## Proyectos destacados

### Ecommerce React

Aplicación ecommerce full-stack con React 19, Vite y Zustand. Incluye gestión de estado para usuario y carrito, backend de demostración, validación de contraseñas y medidas de protección como rate limiting.

- Demo: https://tiendareactver.netlify.app/
- Código: https://github.com/fn91/EcommerceReact

### StateFlow

Herramienta pedagógica para visualizar el flujo de información en una arquitectura React utilizando Context API. Incluye ejemplos de estado global, Provider/Consumer, prevención de Prop Drilling y optimización de renderizado.

- Demo: https://stateflow.netlify.app/
- Código: https://github.com/fn91/state-flow

### DecisionLab

Aplicación desarrollada con JavaScript para modelar procesos de toma de decisiones mediante lógica matemática y resolución de problemas.

- Demo: https://decisionalab.netlify.app/
- Código: https://github.com/fn91/decision-lab

### PromptCraft
